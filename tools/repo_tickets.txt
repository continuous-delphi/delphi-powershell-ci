Title: Add Invoke-DelphiCodesign with Sign and Verify actions
Issue: #12
Status: closed
Labels: enhancement
Body:
Add code signing support to the CI module by bundling
`delphi-codesign-azure.ps1` and exposing `Invoke-DelphiCodesign` as a
public command with `Sign` and `Verify` pipeline actions.

## Design

Use the established engine pattern (like Build has MSBuild/DCCBuild,
Coverage has DelphiCodeCoverage/radCodeCoverage). The codesign engine
abstraction allows future signing providers beyond Azure Trusted Signing
(e.g. local certificate store, DigiCert, other cloud HSMs).

### Public command: Invoke-DelphiCodesign

Parameters following the `<Action><Param>` naming convention:

- `-CodesignAction` -- `Sign` or `Verify` (ValidateSet)
- `-CodesignEngine` -- `AzureTrustedSigning` (default, only engine for now)
- `-CodesignFiles` -- string array of files to sign (Sign action)
- `-CodesignFilePath` -- single file to verify (Verify action)
- `-CodesignSignToolPath` -- explicit signtool.exe path
- `-CodesignDlibPath` -- Azure.CodeSigning.Dlib.dll path
- `-CodesignMetadataPath` -- metadata.json path
- `-CodesignEnvFile` -- .env file for Azure credentials
- `-CodesignFormat` -- output format (object/text/json)

### Pipeline action: Codesign

JSON config (`delphi-ci.json`) support:

```json
{
  "action": "Codesign",
  "jobs": [
    {
      "name": "Sign release binaries",
      "codesignAction": "Sign",
      "files": ["projects/cli/Win32/Release/app.exe"],
      "envFile": ".env"
    },
    {
      "name": "Verify signatures",
      "codesignAction": "Verify",
      "filePath": "projects/cli/Win32/Release/app.exe"
    }
  ]
}
```
